Literature Review

Diabetes Prediction Using Machine Learning

This literature review discusses four research studies related to diabetes prediction using machine learning techniques, particularly studies that use the Pima Indians Diabetes Dataset.

Paper 1: Pima Indians Diabetes Mellitus Classification Based on Machine Learning (ML) Algorithms

- Authors: Victor Chang, Jozeene Bailey, Qianwen Ariel Xu, Zhili Sun
- Year: 2022
- Journal: Neural Computing and Applications
- DOI: https://doi.org/10.1007/s00521-022-07049-z

Summary:

This study investigated diabetes classification using the Pima Indians Diabetes Dataset and three machine learning algorithms: Naive Bayes, Random Forest, and J48 Decision Tree. The findings showed that Naive Bayes performed well with carefully selected features, while Random Forest benefited from using a larger number of features.

Paper 2: Diabetes Prediction Using Machine Learning and Explainable AI Techniques

- Authors: Isfafuzzaman Tasin, Tansin Ullah Nabil, Sanjida Islam, Riasat Khan
- Year: 2022
- Journal: Healthcare Technology Letters
- DOI: https://doi.org/10.1049/htl2.12039

Summary:

This research developed a diabetes prediction system using the Pima Indians Diabetes Dataset and additional data collected from 203 female employees in Bangladesh. The researchers tested several classification algorithms and used XGBoost with ADASYN to achieve an accuracy of 81%, while LIME and SHAP were used to explain the model's predictions.

Paper 3: Comparative Analysis of Machine Learning Models for Diabetes Prediction: A Cross-Dataset Study of Bangladeshi and Pima Indian Populations

- Authors: Mahmudul Islam, Syed Tangim Pasha, Jahanggir Hossain Setu, Nabarun Halder, Ashraful Islam, M. Ashraful Amin
- Year: 2024
- Conference: 7th Asia Conference on Cognitive Engineering and Intelligent Interaction (CEII 2024)
- DOI: https://doi.org/10.1109/ceii65291.2024.00019

Summary:

This study compared diabetes prediction models using two datasets: the Pima Indians Diabetes Dataset and a Bangladeshi DiaHealth dataset. Random Forest achieved 73.38% accuracy on the Pima dataset and 93.93% on the Bangladeshi dataset, highlighting the importance of evaluating models across different populations.

Paper 4: Machine Learning Algorithm-Based Prediction of Diabetes Among Female Population Using PIMA Dataset

- Authors: Afshan Ahmed, Jalaluddin Khan, Mohd Arsalan, Kahksha Ahmed, Abdelaaty A. Shahat, Abdulsalam Alhalmi, Sameena Naaz
- Year: 2025
- Journal: Healthcare, 13(1), 37
- DOI: https://doi.org/10.3390/healthcare13010037

Summary:

This study applied Principal Component Analysis and exploratory data analysis to examine the Pima Indians Diabetes Dataset. Four machine learning algorithms were evaluated, and Random Forest achieved the best reported accuracy of 80%, with 82% precision and 88% sensitivity.

Research Gap

Previous studies have explored different machine learning algorithms for diabetes prediction, but their performance varies depending on data preprocessing, feature selection, and population characteristics. This project focuses on comparing Logistic Regression and Random Forest using a consistent preprocessing pipeline and multiple evaluation metrics, including accuracy, precision, recall, F1-score, and ROC-AUC. The experiment also investigates whether an additional Glucose-BMI interaction feature contributes to prediction performance.
